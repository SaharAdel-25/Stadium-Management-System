## 🌟 نبذة عن المشروع | Overview
مشروع ويب متكامل يهدف إلى أتمتة وتسهيل عملية حجز وإدارة المنشآت الرياضية بأسلوب عصري ومنظم. يركز المشروع على تقديم تجربة مستخدم (UI/UX) سلسة مع بناء خلفية برمجية (Backend) تلتزم بمعايير الأمان ونظافة الكود (Clean Code).

A full-stack web application designed to automate and streamline the booking and management of sports stadiums. This project focuses on delivering a high-quality user experience (UI/UX) while ensuring the backend architecture is secure, scalable, and follows clean code principles.

## 🛠️ المواصفات التقنية | Technical Stack

### **Frontend**
- **HTML5 & CSS3:** لبناء هيكل وتصميم متجاوب.
- **JavaScript:** لإضافة التفاعل والمنطق البرمجي في الواجهة.

### **Backend**
- **Node.js & Express.js:** لإدارة الخادم ومعالجة البيانات.
- **Security:** فصل البيانات الحساسة باستخدام أفضل الممارسات البرمجية.

### **DevOps**
- **Git & GitHub:** لإدارة النسخ والتحكم في الإصدارات.
- **GitHub Pages:** لاستضافة النسخة التجريبية للموقع.

## ✨ المميزات | Highlights
* ✅ **Responsive Design:** Optimized for all screen sizes (Mobile/Desktop).
* ✅ **Clean Architecture:** Organized file structure for maintainability.
* ✅ **Secure Practices:** Separation of configuration from source code.
